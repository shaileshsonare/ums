📋 Project Overview

A modern, full-stack employee management system built with Node.js and vanilla JavaScript. Features secure JWT authentication, complete CRUD operations, and a premium UI with glassmorphism design.

Key Features

  • 🔐 Secure JWT-based authentication with bcrypt password hashing
  • 👥 Complete employee CRUD operations (Create, Read, Update, Delete)
  • 🔍 Real-time search and filtering
  • 🎨 Modern UI with glassmorphism and gradient effects
  • 📱 Responsive design for all devices
  • 🛡️ Protected API routes with middleware
  • ✅ Form validation on frontend and backend

Technology Stack

Backend

  • Node.js
  • Express.js
  • MySQL2 (MariaDB)
  • JWT (jsonwebtoken)
  • Bcrypt.js
  • CORS
  • Dotenv

Frontend

  • Vanilla JavaScript
  • HTML5
  • CSS3 (Custom Properties)
  • Fetch API
  • LocalStorage API
  • Google Fonts (Inter)

Database

  • MariaDB / MySQL
  • Connection Pooling
  • Prepared Statements
  • Auto-table Creation

🔌 API Endpoints

Authentication Endpoints

Method Endpoint Description Auth Required
POST /api/auth/register Register new user account ❌ No
POST /api/auth/login Login and receive JWT token ❌ No

Register Request Body

{
  "username": "string (required)",
  "password": "string (min 6 chars, required)"
}

Login Request Body

{
  "username": "string (required)",
  "password": "string (required)"
}

Success Response

{
  "success": true,
  "message": "Login successful",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "username": "testuser"
  }

Employee Endpoints

Method Endpoint Description Auth Required
GET /api/employees Get all employees ✓ JWT
GET /api/employees/:id Get single employee by ID ✓ JWT
POST /api/employees Create new employee ✓ JWT
PUT /api/employees/:id Update employee by ID ✓ JWT
DELETE /api/employees/:id Delete employee by ID ✓ JWT

💾 Database Schema

Entity Relationship Diagram

erDiagram USERS ||--o{ SESSIONS : "authenticates" EMPLOYEE { int id PK "Auto Increment" varchar name UK "Unique, NOT NULL" varchar department "NOT NULL" int salary "NOT NULL" int phone "NOT NULL, Indexed" } USERS { int id PK "Auto Increment" varchar username UK "Unique, NOT NULL" varchar password "Hashed, NOT NULL" timestamp created_at "Default CURRENT_TIMESTAMP" } SESSIONS { string jwt_token "Stored in localStorage" int user_id FK timestamp expires_at "24 hours from issue" }

Users Table

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Employee Table

CREATE TABLE employee (
    id INT(11) AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) UNIQUE NOT NULL,
    department VARCHAR(50) NOT NULL,
    salary INT(11) NOT NULL,
    phone INT(11) NOT NULL,
    KEY phone_idx (phone)
);
Note: The phone field uses INT(11) which limits values to 2,147,483,647. For production, consider using VARCHAR(15) or BIGINT for international phone numbers.

🛡️ Security Features

Security Architecture

Security Measures

  • Password Hashing: Bcrypt with 10 salt rounds
  • JWT Authentication: Tokens expire after 24 hours
  • Protected Routes: Middleware validates JWT on every request
  • SQL Injection Prevention: Prepared statements with parameterized queries
  • CORS: Cross-Origin Resource Sharing enabled
  • Input Validation: Frontend and backend validation
  • Unique Constraints: Prevent duplicate usernames and employee names
  • Environment Variables: Sensitive data stored in .env file

⚙️ Setup Guide

Prerequisites

  • Node.js (v14 or higher)
  • MariaDB or MySQL (v10.3 or higher)
  • npm or yarn package manager

Installation Steps

flowchart TD Start([Start Setup]) --> Clone[Clone Repository] Clone --> Install[npm install] Install --> DB[Create Database] DB --> Env[Configure .env] Env --> Start_Server[Start Server] Start_Server --> Open[Open Frontend] Open --> Register[Register Account] Register --> End([Setup Complete]) style Start fill:#667eea style End fill:#4caf50

1. Clone and Install

git clone <repository-url>
cd ums
npm install

2. Database Setup

mysql -u root -p
CREATE DATABASE company;
USE company;

-- Employee table (if not exists)
CREATE TABLE employee (
    id INT(11) AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) UNIQUE NOT NULL,
    department VARCHAR(50) NOT NULL,
    salary INT(11) NOT NULL,
    phone INT(11) NOT NULL
);

-- Users table will be created automatically

3. Environment Configuration

# .env file
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=company
JWT_SECRET=your-super-secret-jwt-key
PORT=3000

4. Start Server

node app.js
# Or with nodemon for development
nodemon app.js

5. Access Application

  • API: http://localhost:3000
  • Frontend: Open frontend/index.html in browser
